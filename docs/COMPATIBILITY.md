## 当前实现条件

- ARM64 原生进程，传统 Mach-O 符号／间接导入表，可写 `__DATA` 中的目标接口导入槽。
- 两种目标 API 均有可写导入槽，当前最多计划 8 个槽。
- 单声道 MPEG-4 AAC、采样率 8000/11025 Hz。
- 查询声道布局的原始结果为 `kAudioFileBadPropertySizeError`；其他错误不会被掩盖。
- dylib 必须实际加载。模块不能修复阻止它自身被加载的路径或签名问题。

当前未适配纯 ARMv7、LiveExec32、只提供不可写导入槽的二进制或其他采样率／编码；国际版及其他游戏构建未在此记录中确认。
